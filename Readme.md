# Managing BookStore Using LinkedList

Problem Statement:
Develop a Book Management System that efficiently manages a collection of books using a linked list. Each book should have an ISBN number, a book name, and a quantity. The system should provide functionalities to search for books by ISBN number, sort books by their quantity, insert new books, and allow book purchases.

## Functional Requirements:
### Search by ISBN Number:

Ability to search and retrieve book information using the ISBN number.

### Sort by Quantity:

Sort the books based on their quantities, ensuring that books with lower quantities (less selling books) are listed first.

### Insertion of New Books:

Capability to add new books to the collection, including their ISBN number, name, and initial quantity.

### Purchase Book:

Functionality to purchase a book, which decreases its quantity in the system.
